## Page d'erreur 404

La page d'erreur 404 est la page qui est affichée si une adresse erronée de
votre site est demandée.

#### Répertoire

<pre class="path">
<span style="color:#bbb">theme/fr/</span>modules/404/404.html
</pre>

#### Exemple du code source

	<!DOCTYPE html>
	<html>
	<head>
	   <meta http-equiv="Content-Type" content="text/html; charset=iso-8859-1" />
	   <meta name="keywords" content="{metaKeywords}">
	   <title>{site_nom} | Erreur 404, cette page n'existe pas !</title>
	</head>
	<body>
	   <h1>Erreur 404, cette page n'existe pas !
	   <br />
	   <a href="{racine}/" title="Retour au site">Retour au site</a></h1>
	</body>
	</html>
